# Field mission positioning

A Changing Frontier introduces the existing NISAR explorer through a cinematic, freely navigable story. Astrounit links a place, recorded acquisitions and the tool that can investigate them. The old pixel adventure has been retired.

A demonstration should show actual acquisition dates, an honest preview/model distinction, and a successful handoff into Inspect. User feedback, learning outcomes and award eligibility require their own evidence; the interface alone does not establish them.

See `GAME_IMPLEMENTATION.md`, `GAME_DEMO_SCRIPT.md` and the current project/submission notes for implementation and demonstration details.
